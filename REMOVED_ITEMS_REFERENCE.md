## How to Use This Reference

**When cleaning loot tables, recipes, or advancement files:**

1. Search for items in this list within your data files
2. Remove any entries that match items listed here
3. Use the mod prefix (before the colon) to search by mod category

**Quick Search Tips:**
- Use Ctrl+F to find specific items
- Search by mod name (e.g., "spelunkery:") to find all items from that mod
- Items with (all colors) contain 16 color variants
